# Technical Specification: Phase 0 — Workspace & Repository Setup

- **Task ID:** 0.0
- **Title:** Workspace & Repository Setup
- **Major Phase Branch:** `main` (Baseline setup prior to feature branching)
- **Status:** In Progress

---

## 1. Goal & Architectural Overview

Establish a clean, secure, and production-ready workspace baseline for **Project Bite** (Photo-first AI calorie & macronutrient tracker).

This phase establishes standard repository rules, configures secret management guidelines, sets up `.gitignore` to prevent sensitive credentials and virtual environment binaries from leaking into source control, provisions environment placeholder files (`.env` and `.env.example`), and creates the initial Git baseline commit.

---

## 2. Technical Requirements

### 2.1 File & Directory Requirements
1. **`.gitignore`**:
   - Comprehensive rules covering Python (`.venv`, `__pycache__`, `*.pyc`, `.pytest_cache`, `.coverage`), environment/secret files (`.env`, `*.pem`, `*.key`), IDE configuration (`.vscode/`, `.idea/`), OS metadata (`.DS_Store`), and future Flutter / frontend build artifacts (`build/`, `.dart_tool/`).
2. **`.env` and `.env.example`**:
   - Environment files supporting strict Pydantic settings loading (`pydantic-settings`).
   - Defined keys:
     - `SUPABASE_POSTGRES_DIRECT_URL` (Direct PostgreSQL connection string for async migrations & connection pooling)
     - `GEMINI_API_KEY` (Gemini Multimodal Vision / LLM API key)
     - `OPENAI_API_KEY` (Optional alternative LLM API key)
     - `USDA_API_KEY` (USDA FoodData Central API key)
     - `SUPABASE_JWT_SECRET` (JWT Secret for validating auth tokens)
3. **`pyproject.toml` / `requirements.txt` Baseline**:
   - Dependency declarations for core stack: `fastapi`, `uvicorn`, `langgraph`, `langchain-google-genai`, `asyncpg`, `pydantic-settings`, `httpx`, `pytest`, `pytest-asyncio`.

---

## 3. Security & Performance Standards

- **Zero Secret Leakage:** `.env` must NEVER be committed to Git. `.gitignore` must explicitly block `.env` and credential files.
- **Environment Template:** `.env.example` must contain placeholder non-sensitive values so developers can easily copy and configure environment variables.
- **Clean Git Baseline:** Establish an initial commit containing setup files (`PROJECT_PLAN.md`, `.gitignore`, `.env.example`, `specs/`).

---

## 4. Step-by-Step Implementation Blueprint

1. **Step 4.1 — Author `.gitignore`**: Create a comprehensive `.gitignore` in the repository root.
2. **Step 4.2 — Create `.env` & `.env.example`**: Write `.env.example` with safe default placeholders, and initialize `.env` locally.
3. **Step 4.3 — Create baseline Python dependency manifest**: Write `requirements.txt` or setup minimal package structure.
4. **Step 4.4 — Create baseline commit**: Add baseline files to Git staging and execute initial commit on `main`.
5. **Step 4.5 — Remote repository setup instructions**: Provide commands/steps to attach a remote GitHub repository (`bite-backend`) and push the `main` branch.
